# Retrievo Phase II — Manual Test Checklist

Run each test yourself and record the actual outcome before reporting a Pass.

- [ ] `index.html` opens in a browser without a blank page.
- [ ] Search by an item name filters the listings.
- [ ] Type filter shows only Lost or only Found reports.
- [ ] Category filter works.
- [ ] Submit a valid lost-item report.
- [ ] Submit a valid found-item report.
- [ ] New report remains after refreshing the same browser.
- [ ] View details displays the correct item and contact.
- [ ] Mark returned changes the status and count.
- [ ] Search with no matches shows the empty state.
- [ ] Layout is usable on a narrow/mobile screen.

## Report accuracy
This is a local browser prototype using localStorage, not a shared server/database. Only describe features as completed after testing them.
