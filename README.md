# Retrievo — A Smart College Lost and Found Platform

Retrievo is a BSc CS project prototype to help a college community report and search for lost and found belongings.

## Features in this prototype
- Responsive home page and listing cards
- Report lost and found items
- Search by item name, description, category, or location
- Filter by report type, category, and status
- View item details and reporter contact
- Mark a report as returned
- Save records using browser localStorage
- Sample demonstration records

## Run locally
1. Download or clone this repository.
2. Open `index.html` in Chrome, Edge, or another modern browser.
3. Try searching, adding a report, viewing details, and marking an item as returned.

No installation or build step is needed.

## Limitation
This prototype stores records in the current browser only. It does not yet use a shared online database or server, so records do not sync across different devices. Sample records are demo data; do not enter sensitive real information.

## Technologies
HTML, CSS, JavaScript, browser localStorage.
